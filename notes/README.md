# Notes Index

This directory should stay small and current. Put raw sweeps, dated audits, binary artifacts, and superseded plans under `notes/archive/`.

## Active Notes

- `research_flow.md`: high-level research framing.
- `current_status.md`: current implementation state and immediate blockers.
- `selector_eval_latest_results.md`: compact current frontier/result summary.
- `runbook.md`: current commands only.
- `benchmark_readiness_checklist.md`: benchmark readiness gates.
- `debug_playbook.md`: debugging checklist.
- `attention_approximation_progress_report.md`: narrative progress report.
- `attention_output_quality_metrics.md`: metric definitions and interpretation.
- `public_longdecode_benchmarks.md`: public long-decode benchmark setup.
- `findings_log.md`: compact high-signal findings index.

## Archive Policy

- Keep full historical logs in `archive/status_history/`.
- Keep selector/proxy survey outputs in `archive/selector_surveys_2026-05/`.
- Keep benchmark audit fragments in `archive/benchmark_audits_2026-05/`.
- Keep RetrievalAttention/Roar graph sweep artifacts in `archive/ra_graph_sweeps/`.
- Keep old handoff checkpoints in `archive/checkpoints/`.
- Keep administrative cleanup notes in `archive/admin/`.

If a result becomes part of the current argument, summarize it in `selector_eval_latest_results.md` or `current_status.md` and link to the archived source.
