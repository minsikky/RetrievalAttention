# Notes Archive

Archived notes are preserved for traceability, not used as the day-to-day entrypoint.

## Layout

- `status_history/`: full pre-cleanup versions of large append-only docs.
- `selector_surveys_2026-05/`: mass/L2 selector surveys, PQCache/SparQ/MagicPIG/Self-Indexing/TurboQuant/PQ variants, and related proposals.
- `benchmark_audits_2026-05/`: dated RULER/LongBench wrapper audits, drift reports, readiness tables, and small comparison fragments.
- `ra_graph_sweeps/`: old RetrievalAttention/Roar graph sweeps, recall curves, graph-builder baselines, and generated artifacts.
- `checkpoints/`: old context checkpoint handoffs.
- `admin/`: repo-context cleanup notes.

Do not add new raw sweep dumps to top-level `notes/`; archive them here or write them under the relevant result directory.
